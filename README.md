# AI-Driven Multi-Cloud High Availability and Automatic Failover System

## Description

This project is a final-year engineering project that aims to improve application availability by monitoring services deployed across multiple cloud environments, predicting potential failures using machine learning, and automatically performing failover to a healthy cloud environment.

## Project Goal

The system will:

- Monitor cloud application health
- Collect system performance metrics
- Detect service failures
- Predict potential failures using AI/ML
- Automatically perform cloud failover
- Record failover events
- Provide a monitoring dashboard

## Planned Cloud Providers

- AWS
- Microsoft Azure
